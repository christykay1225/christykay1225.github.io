This bar chart shows the ten most common license types in the dataset by total count. The x-axis encodes the number of licenses (Quantitative) and the y-axis encodes the license type (Nominal), sorted by count. Each bar is colored by license type using a nominal color scheme to visually distinguish categories. The data was transformed using value_counts() to aggregate counts per license type, then filtered to the top 10.

This bar chart shows the number of licenses per license type for a selected city. Use the dropdown to pick a city and the chart updates to show that city's license breakdown. The x-axis encodes license type (Nominal), y-axis encodes count (Quantitative), and colors represent license type. Data was filtered to the top 15 cities.
